## What is _not_ covered by this

CEFR levels written into the `lexicon` table by `pnpm level:lexicon` (phase 1) are model output, not
data from any source above. They are marked `level_source = 'job'` and can be told apart from the
human-curated `'cefrj'` / `'octanove'` values at any time — which is also why the loader will not
overwrite the latter with the former.
